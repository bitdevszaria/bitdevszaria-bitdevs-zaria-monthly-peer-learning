# Contributing

Thanks for helping maintain the BitDevs Zaria Monthly Peer Learning plans.

## Adding a monthly plan

1. Create a month folder directly in the repository root using `YYYY-MM-month-topic/`.
2. Put the monthly theme, required reading, learning objectives, and month-end output in that folder's `Introduction.md`.
3. Create a separate Markdown file for each session, with its focus, activity, discussion prompts, and notes.
4. Keep edition-specific chapter references flexible when numbering may differ.
5. Update the monthly-plan list in the root `README.md`.
6. Submit the changes for review by the organizers before treating them as the current plan.

## Editing an existing plan

Make focused edits, preserve useful context, and flag any changes to dates, reading requirements, or session expectations for organizer review. Avoid publishing private attendee information in this repository.
